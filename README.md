# Elamir Stream Player — Downloads

Official downloads of **Elamir Stream Player** for Windows and Android.
This repository contains release files only (no source code).

- **Windows:** download `ElamirStreamPlayer-Windows-Setup-*.exe` from the latest release.
- **Android:** download the `.apk` from the latest release.
- **iPhone / iPad:** coming to the App Store.
- Every release includes `SHA256SUMS.txt`, signed (`SHA256SUMS.txt.sig`) — the Windows app only installs updates that carry a valid signature.

Elamir Stream Player is a media player: it does not provide any channels or content. Use it with your own subscription or playlist.
